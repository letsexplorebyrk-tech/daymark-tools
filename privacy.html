Daymark Tools / practical planning

Privacy Policy

Effective date: August 25, 2026. Daymark Tools is designed to work locally in your browser. Tool entries and language choices are saved in browser storage unless you clear them. Daymark does not provide an account system or receive these entries on a Daymark server.

Location

The trip tool requests location only after you press its location button. Coordinates remain in memory for the directions action and are not saved by Daymark. Opening a map provider is a separate choice governed by that provider’s policies.

Analytics and advertising

Daymark uses Microsoft Clarity for site analytics. Google AdSense verification code is active while the site is under publisher review; ads are not shown until Google approves the site and ad serving is enabled. If advertising is enabled, this policy will be updated to explain relevant cookies, interest-based advertising, and opt-out choices.

Your choices

You can clear a tool’s saved data, remove site storage in browser settings, decline location permission, and select a language manually. Browser storage is available to people using the same browser profile on your device.
